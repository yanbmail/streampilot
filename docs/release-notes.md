# v1.2.0 · 多码率阶梯转码 / 一周排播 / 推流模板

这一版补上了三件「真正日常在用」的事：一次解码出多档码率、按周自动开播停播、把常用参数存成模板复用。

## 新增：多码率阶梯转码

一次解码，最多输出 4 档，每档可以推不同的平台。

- 「推流目标」页签打开阶梯开关后，点「生成 1080/720/480」一键出三档（6000 / 3000 / 1200 kbps，preset 与 profile 已按高度选好）
- 每档独立设置：分辨率、码率、帧率、preset、协议、服务器地址 / 推流码，或直接填完整 URL
- 底层是 `-filter_complex split=N`，**只解码一次**；4 档 1080/720/480 的总负载约 8.5 Mbps，比开三个任务省很多 CPU
- 支持 RTMP / RTMPS / RTSP / SRT / UDP / HTTP-FLV / HLS / 录制文件
- HLS 档落在 `hls/<任务ID>_r1`、`_r2`…，表单里直接给出播放地址
- 任一档地址写错只影响那一档，其余继续推

实测：三档同推后 `ffprobe` 校验输出为 1920×1080 / 1280×720 / 854×480，落盘体积按码率等比（9.0 / 4.5 / 2.0 MB）。

## 新增：排播表（一周定时播）

左侧「排播表」是一个 7 天 × 24 小时的周视图。

- 点空白格 → 在那一刻新建；点色块 → 编辑；红线是当前时间
- 每条指定：名称、关联任务、星期几（多选，含工作日 / 周末 / 每天 / 清空快捷）、开始时刻、结束方式
- 结束方式两种：**指定时刻**（20:00→22:00）或**按时长**（20:00 起播 90 分钟）
- 跨午夜自动识别：`23:30 → 01:00` 会标注「跨午夜」，第二天凌晨正常停
- 到点自动开播 / 自动停播；同一任务被多条排播共用时不会误停（等最后一条结束）
- 「立即开播 N 分钟」用来临时试跑，到点自动断，不影响既定排播
- 引擎每 10 秒对一次表；起播失败退避 60 秒重试，失败原因标在列表里
- 总开关整体暂停，单条也能单独禁用

## 新增：推流模板

- 从现有任务一键「存为模板」；也能建空白模板、复制一份改名
- 模板只存「画面 + 音频 + 目标 + 录制 + 阶梯」，**不含输入源**，套用时不会把源改掉
- 任务编辑器顶部可直接套用；模板页可勾多个任务**批量套用**；还能「用模板新建任务」
- 模板卡片显示画面规格、音频、主目标（阶梯模式显示「阶梯 N 档 · 首档 host」）与录制标记

## 修复

- 修复配置加载时版本号不会升级到当前版本的问题（旧配置的 `version` 会一直停在旧值）
- 配置结构升级到 v4：旧配置自动补齐 `schedule`、`templates`、`ladder`，不需要手动迁移

## 升级提示

- 直接覆盖安装即可，`~/.streampilot/config.json` 会自动补默认值；升级前的配置会自动存一份 `.bak`
- 老任务默认「阶梯关闭」，行为与 v1.1.x 完全一致
- 模板会连推流码一起保存，导出的配置文件里有平台推流码，分享前请自行删掉
